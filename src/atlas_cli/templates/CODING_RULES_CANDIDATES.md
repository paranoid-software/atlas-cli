# Coding rules — candidates

Rules found while working in this Atlas that may belong in the coding-rules source declared in
`_settings/atlas.toml`. A candidate is in force in this Atlas from the moment it is written
here — agents follow it like a rule of the source. It is promoted only in a dedicated session,
with the human's approval, never written straight to the source; promotion widens it to every
project.

## Entry format
- **Candidate:** <the rule, one or two sentences>
- **Why it generalizes:** <why it holds beyond this Atlas>
- **Source:** <where it surfaced>
