# Coding rules — deviations

Deliberate divergences, in this Atlas, from a rule of the coding-rules source declared in
`_settings/atlas.toml`: "the rule says X; here we do Y because …". Not a list of rules that
simply don't apply.

## Entry format
- **Rule:** <the rule, or its id in the source>
- **Here:** <what this Atlas does instead>
- **Because:** <the reason>
